# @deepseek-ai/dsh-auth-local

[English](README.md) | [简体中文](README.zh.md) | 繁體中文

提供 `ctx.localAccounts`，即僅所有者可讀的 JSON 帳戶儲存，供專門在 DSH 身分驗證閘道註冊的使用者使用。密碼透過 scrypt 和每帳戶隨機鹽值派生；文件只包含派生 hash 和帳戶資料。DSH 不載入該包，也不讀取其文件。

必需的 `path` 位於閘道獨立的 `DSH_AUTH_HOME` 下。建立操作會序列化跨行程寫入方，以 `0600` 模式原子替換完整的版本化文件，拒絕大小寫不敏感的重複使用者名稱或電子郵件地址，並返回 `local:<uuid>` 身份。身分驗證會先讀取並驗證完整文件，再以常數時間相等性比較新派生值。

## 模型體驗

無，因為該儲存執行在獨立的身分驗證閘道中且不呼叫模型。

#### KV Cache 影響

無；帳戶欄位和密碼 hash 絕不進入模型提供方請求。

## 已知限制與延後工作

- 尚未實作密碼重設、電子郵件驗證、MFA、管理帳戶操作和橫向資料庫複製。
