# @deepseek-ai/dsh-auth-local

[English](README.md) | 简体中文 | [繁體中文](README.zh-tw.md)

提供 `ctx.localAccounts`，即仅所有者可读的 JSON 账户存储，供专门在 DSH 身份验证网关注册的用户使用。密码通过 scrypt 和每账户随机盐值派生；文件只包含派生 hash 和账户资料。DSH 不加载该包，也不读取其文件。

必需的 `path` 位于网关独立的 `DSH_AUTH_HOME` 下。创建操作会串行化跨进程写入方，以 `0600` 模式原子替换完整的版本化文档，拒绝大小写不敏感的重复用户名或电子邮件地址，并返回 `local:<uuid>` 身份。身份验证会先读取并验证完整文档，再以常量时间相等性比较新派生值。

## 模型体验

无，因为该存储运行在独立的身份验证网关中且不调用模型。

#### KV Cache 影响

无；账户字段和密码 hash 绝不进入模型提供方请求。

## 已知限制与延后工作

- 尚未实现密码重置、电子邮件验证、MFA、管理账户操作和横向数据库复制。
