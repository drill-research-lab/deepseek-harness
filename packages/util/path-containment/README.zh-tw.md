# dsh-path-containment

[English](README.md) | [简体中文](README.zh.md) | 繁體中文

DeepSeek Harness 的共享路徑圍堵輔助工具。

## 路徑圍堵

`isPathUnder(path, root)` 回報一個規範化的目標路徑是否位於某個根目錄之下或與其相同。詞法快速路徑處理普通的規範化寫法；當兩種寫法不一致時，函式遍歷目標的現有祖先路徑並與根目錄比較檔案系統身分，從而識別 Windows 長檔名/8.3 別名與大小寫差異，而不會把圍堵弱化為文字近似。

`caseSensitive` 參數用於詞法比較時保留或摺疊大小寫，預設採用宿主檔案系統約定（除 Windows 外為 `true`）。

該包刻意保持規模小且不依賴 harness，以便產品包強制相同的路徑圍堵而不必彼此依賴。

## 已知限制與暫緩事項

- **呼叫方負責規範化**：`isPathUnder()` 假設其 `path` 參數已經是規範化的（其現有祖先路徑已透過 `fs.realpath` 解析）。比較帶有 `..` 段或符號連結祖先的未規範化寫法時，呼叫方必須先做規範化；詞法快速路徑只對規範化輸入安全。
- **圍堵不是安全邊界**：該檢查是在可信代碼中對模型或使用者選擇的路徑所做的信任檢查；內核級隔離仍是沙箱層的職責。
