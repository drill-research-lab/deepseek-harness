# dsh-path-containment

[English](README.md) | 简体中文

DeepSeek Harness 的共享路径围堵辅助工具。

## 路径围堵

`isPathUnder(path, root)` 报告一个规范化的目标路径是否位于某个根目录之下或与其相同。词法快速路径处理普通的规范化写法；当两种写法不一致时，函数遍历目标的现有祖先路径并与根目录比较文件系统身份，从而识别 Windows 长文件名/8.3 别名与大小写差异，而不会把围堵弱化为文本近似。

`caseSensitive` 参数用于词法比较时保留或折叠大小写，默认采用宿主文件系统约定（除 Windows 外为 `true`）。

该包刻意保持规模小且不依赖 harness，以便产品包强制相同的路径围堵而不必彼此依赖。

## 已知限制与暂缓事项

- **调用方负责规范化**：`isPathUnder()` 假设其 `path` 参数已经是规范化的（其现有祖先路径已通过 `fs.realpath` 解析）。比较带有 `..` 段或符号链接祖先的未规范化写法时，调用方必须先做规范化；词法快速路径只对规范化输入安全。
- **围堵不是安全边界**：该检查是在可信代码中对模型或用户选择的路径所做的信任检查；内核级隔离仍是沙箱层的职责。
