# @deepseek-ai/dsh-acp

[English](README.md) | [简体中文](README.zh.md) | 繁體中文

透過 JSON-RPC stdio 提供的僅面向自動化的 [ACP（Agent Client Protocol）](https://agentclientprotocol.com) 伺服器。程序化用戶端可以建立新 harness agent（代理）、傳送文字／圖片提示詞、收集已提交的 assistant 文字／圖片、按策略回應一次性權限請求並取消工作。倉庫中的主要用戶端是 [`dsh-subagent-acp`](../../subagent/subagent-acp/README.md)。

此包是傳輸配接器，而非 UI 整合或能力 seam。它不公開編輯器導覽、transcript（文字記錄）重播、命令、模式、設定選擇器、資訊徵集、推理（reasoning）、計畫、標題或工具展示。互動式算繪與向使用者提問屬於 Web 宿主和用戶端模組。

## 外掛程式

`apply(ctx, config)` 在 stdin/stdout 上打開 `AgentSideConnection` 並驅動 `ctx.agents`。Stdout 專用於協定幀。

| 設定 | 預設值 | 含義 |
|---|---|---|
| `provider` | 無 | 每個已建立 agent 的初始提供方路由。 |
| `model` | 無 | 每個已建立 agent 的初始模型。 |

兩個欄位都是選填的，以便由另一個 agent/request 監聽器提供目標。可執行的 ACP 組合同時要求兩者。

## 協定約定

| 方法 | 行為 |
|---|---|
| `initialize` | 協商受支援的版本。只有掛載持久附件儲存，且設定的確切提供方／模型解析後明確支援圖片輸入時，才公佈圖片提示詞能力；音訊與嵌入上下文保持 false。不公佈工作階段、編輯器、終端機、檔案系統或 MCP 能力。 |
| `authenticate` | 空操作，因為伺服器不公佈身分驗證方法。 |
| `session/new` | 以絕對路徑作為主 `cwd` 建立新 agent；接受空的 `additionalDirectories` 和 `mcpServers`，拒絕非空值。 |
| `session/prompt` | 保留文字與受支援內聯圖片塊的順序，將資源連結算繪為帶方括號的文字引用，並拒絕音訊、嵌入資源、格式錯誤／空輸入，或在未公佈能力時提交圖片。它會先校驗完整圖片批次並重新檢查工作階段的最新確切路由，再保存任一成員；在使用者事件前提交全部圖片；每個工作階段只允許一個正在處理的請求，並等待准入，以及訊息入隊後的整個 Agent 空閒和有序輸出交付全部停穩。正常完全靜止時報告 `end_turn`；顯式 ACP 取消、資源釋放，或准入被丟棄的提示詞（無輪次槽位）時報告 `cancelled`。 |
| `session/cancel` | 標記並中止正在進行的准入，但不會取消或等待同一 Agent 上無關的既有工作；該提示詞進入 Agent inbox 後，才會取消指定的 Agent 並等待自有區間停穩。不發布遲到的使用者訊息，提示詞以 `cancelled` 結帳。沒有進行中的提示詞時會取消自主工作；未知 id 為空操作。 |
| `session/update` | 為已提交 `assistant/message` 中的每個非空文字或圖片塊寄出一個 `agent_message_chunk`，並保留順序。圖片在以內聯 base64 交付前會重新讀取並校驗完整性。省略原始增量和非訊息事件。 |
| `session/request_permission` | 為攜帶工具呼叫 id、由橋接層擁有的批准請求提供一次性允許／拒絕選項。用戶端可以自動回答。 |

一個連線可以擁有多個工作階段。橋接層以帶品牌的工作階段 id 作為記錄鍵，並在路由事件或權限請求前檢查 agent 是否為同一對象。每個工作階段都有獨立的提示詞槽位、工作區、取消路徑和資源釋放器。

已提交訊息輸出有意犧牲逐 token 輸出的低延遲，以換取乾淨的自動化結果。未提交的提供方區塊和重試嘗試無法洩漏部分文字或圖片；推理與工具活動仍保留在工作階段日誌中，以便其他介面觀測。由於附件讀取是非同步的，每個工作階段會序列交付內容；已提交圖片缺失或損壞時，提示詞回應會失敗，而不會發出預留位置。

## 生命週期

用戶端中斷連線與 Cordis 釋放共用同一個記憶化清理流程。橋接層先拒絕新工作階段和提示詞，取消並等待提示詞准入、agent 活動和有序輸出交付全部停穩，然後只 drain 此連線確切擁有的 Agent 之下的可繼續後代，再平行釋放這些 handle，並等待全部結果結帳後才報告失敗。其他共享該上下文的前端會保留其可繼續森林和准入。因此，僅 ACP 的外掛程式重載不會殘留 agent。

ACP 要求每個提示詞回應都攜帶 `stopReason`，但橋接層不聲稱它表示提示詞專屬的輪次結果。操作區間從提示詞進入 Agent inbox 開始，在准入、整個 Agent 空閒和有序輸出交付全部停穩後結束；inbox 接收前無關 Agent 工作的失敗不會歸因給該提示詞。已提交的 assistant 訊息會在自有區間內流式輸出，Agent 進入空閒狀態前發生的 steering（中途引導）或注入工作也可能參與其中。結帳優先級依次為顯式取消、輸出交付失敗、區間內 Agent 失敗、關聯輪次結束。因 token 上限而結束時以 `end_turn` 結帳；關聯模型錯誤也只會在同一個完全靜止邊界拒絕提示詞。

## 執行

`pnpm --dir /path/to/deepseek-harness run demo:acp` 啟動倉庫的自動化伺服器組合。父 harness 可以透過 [`@deepseek-ai/dsh-subagent-acp`](../../subagent/subagent-acp/README.md) spawn 它；其他 ACP 用戶端只需上述核心方法。

## 模型體驗

### 提示詞文字與圖片

#### 模型看到的內容

`session/prompt` 會在一條使用者訊息中保留文字／圖片順序；相鄰文字會拼接，資源連結則表示為帶方括號的 `[resource_link name=… uri=…]` 引用，模型可以使用自身工具打開它。內聯圖片 base64 在批次准入後即被丟棄，因此持久訊息只包含經過校驗的附件引用。協定中繼資料、用戶端能力、權限選擇和工作階段 id 絕不進入模型請求。

#### Token 影響

提示詞 token 與圖片費用取決於資料，並保留在該工作階段的歷史中直到上下文壓縮（context compaction）。並行 ACP 工作階段保留獨立上下文。

#### KV Cache 影響

僅附加；新使用者訊息位於可複用請求前綴之後，不會使先前快取條目失效。

### 權限決策

#### 模型看到的內容

不會直接看到任何內容。所屬工具透過常規工具結果路徑記錄其結果：允許、拒絕、取消或不可用。

#### Token 影響

只有所屬工具的結果會貢獻 token。

#### KV Cache 影響

僅透過所屬工具的結果追加。

## 已知限制與暫緩事項

- **僅新工作階段**：不支援載入、列出、復原、刪除和 fork。
- **僅光柵圖片和一個 workspace**：圖片提示詞要求持久儲存以及明確聲明支援圖片輸入的確切路由；只接受 PNG、JPEG、WebP 和 GIF。音訊、嵌入資源、非空附加目錄和 MCP 伺服器都會被拒絕；資源連結只會展平為文字引用，不會取得其內容。
- **僅已提交答案**：即時進度、推理、工具活動、計畫、標題和用量不會透過協定傳輸。
- **由連線管理的生命週期**：一個連線會釋放其所有工作階段；尚未實作單個工作階段關閉功能。
