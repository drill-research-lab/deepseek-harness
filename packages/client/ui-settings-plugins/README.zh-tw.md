# dsh-client-ui-settings-plugins

[English](README.md) | [简体中文](README.zh.md) | 繁體中文

**外掛程式**設定分區及其**外掛程式設定**分頁標籤。該分區擁有標題與緊湊的標籤欄；功能外掛程式透過 `settings.plugins.tab` 貢獻頁面。本包自己的分頁標籤為每個設定由使用者擁有的 Host 外掛程式展示一張可展開卡片。卡片展示外掛程式名稱及其管轄範圍；就地展開後是綁定到該外掛程式 settings 命名空間的手寫控制元件，每個欄位標注使用者是否覆蓋過它，並提供重設回部署組裝值的入口。

## 這裡會出現什麼

“外掛程式設定”分頁標籤讀取 Host 服務了哪些 settings 命名空間，並為每個命名空間派發一個 slot 鍵，因此算繪出來的是兩份帳本的交集：存活 Host 外掛程式註冊的命名空間，以及註冊在這些鍵上的卡片。被服務卻無人認領的命名空間什麼都不算繪——它歸別的介面所有，或本部署沒有為它提供瀏覽器半側；而命名空間未被本部署服務的卡片根本不會被派發，因此未組裝的外掛程式不留任何痕跡，也不會擋住那行空態文案。空態文案要等 Host 的第一次答覆，因此一次尚未答覆的讀取絕不會被讀成“本部署沒有可設定的外掛程式”。卡片按自身註冊的順序出現；對同一個包一起安裝的卡片這是穩定的，對跨外掛程式的卡片則不穩定：包與包之間的 apply 順序是無約束的。

本包自帶的卡片覆蓋 shell 執行器（`bash`）、agent 迴圈的工具呼叫平行度（`agent-loop`）以及 DeepSeek 搜尋提供方（`web-search-deepseek`）。

## 擴充點

本分區聲明根級清單 slot `settings.plugins.tab`，其標籤會成為有序分頁標籤。某個分頁標籤首次被選擇後會保持掛載，因此本機草稿與只讀快照在切換分頁標籤時不會丟失。本包註冊自己的 `configurable` 貢獻，由它聲明巢狀的 `settings.plugin.item` slot——以卡片所編輯的 settings 命名空間為鍵。帶瀏覽器半側的外掛程式把自己的卡片註冊在自己的命名空間上，並擁有它的全部：外觀、控制元件與文案。以命名空間為鍵，正是在本倉庫之外分發的外掛程式能出現在這裡的原因——它在 Host 上註冊命名空間、在瀏覽器裡註冊卡片，由分頁標籤把兩者配對，而無需知道命名空間意味著什麼。分頁標籤遵循貢獻的 `order`；卡片遵循註冊順序。

## 寫入

卡片暫存使用者輸入，只有使用者保存時才寫入。每個控制元件算繪的都是暫存文字，因此螢幕上所見即保存後所存；**放棄修改**丟棄這些草稿，持有未保存修改的卡片即使收起也會在標題上標明。重設暫存的是組裝預設值而非立即寫入；欄位不接受的草稿會阻塞保存，而不是被丟棄。

保存時，每個暫存欄位都透過用戶端 settings scope 寫入，該 scope 用讀取時的命名空間 revision 為每次寫入設柵，因此已與文件脫節的表單會被拒絕，而不是覆蓋並行變更。某個值是否被接受只有 Host 說了算——schema 表達不了的約束歸它的校驗器所有——因此卡片在寫入後回讀分節，報告沒有落盤的保存，並保留這些草稿供使用者修改。

金鑰也可能從別的表層寫入——模型頁尋址的是同一個引用——而那不改變任何 settings 分節，因此卡片會在轉發來的 `credentials/updated` 事件報告它所關注的引用時重讀。

欄位是否被覆蓋，取決於它是否出現在原始使用者層中，而非取決於它的值；重設會清除該欄位，使其重新繼承組裝層。secret 角色的欄位絕不搭乘回應，因此金鑰控制元件初始為空、只報告是否已設定，並經由 credentials 領域而非 settings 分節寫入；空草稿不寫入任何東西，保留已存金鑰。

## 模型體驗

無。該分區算繪瀏覽器設定 UI；它寫入的值只透過擁有這些值的外掛程式到達模型，而這些效應各由其擁有方的包記錄。

#### KV Cache 影響

無；該包既不組裝也不傳送提供方請求。

## 已知限制與暫緩事項

- **只有宿主平面的外掛程式會出現**——由 agent preset 掛載的外掛程式把設定內聯在該 preset 的 `agent.cordis.yml` 中，且根本無法註冊 settings 命名空間（同一 preset 掛載第二個工作階段時會因重複註冊而失敗），因此本分區不會列出它。編輯那些值仍是 preset 編輯器的職責。
- **卡片仍然需要一份瀏覽器 bundle**——瀏覽器半側必須是按用戶端模組系統的 lazy-CJS factory 格式建置的 `dsh.client` 包，而產出它的 `clientBundle` 預設位於 `packages/client/tsdown.client.ts`，並非已發布的包，因此本倉庫之外的外掛程式得自行復刻該建置。bundle 純淨度閘門同時禁止以值的形式匯入本包的卡片外觀與表單模型，所以這樣的卡片要自行擁有暫存與 revision 設柵。
- **被服務的命名空間只在兩種訊號上重讀**——協定通告的是 settings 文件提交與連線重設，而非註冊行為，因此在分頁標籤讀取之後才被其擁有方註冊的命名空間，要等下一次文件提交或重連才會加入清單。
- **shell 卡片跟隨被組裝的執行器**——POSIX 與 PowerShell 兩個執行器家族共用 `bash` 命名空間，因為一個宿主只組裝其中之一，所以被服務的 schema 隨平臺不同（PowerShell 多出 `pwshPath`），儘管卡片在兩者下編輯的都是同樣兩個欄位；而兩者都不組裝的部署不會顯示這張卡片。
